# pudding-notes

A cute, aesthetic note-taking web application with rich text editing, sticker placement, interactive folders, and tactile sound effects.

## 🚀 Features
- 📝 Rich text notes with instant auto-save and manual save shortcuts
- 📂 Folder organization
- 🎨 Drag-and-drop stickers & customization
- 🎵 Interactive tactile audio feedback
- ⚡ Powered by Vite

## 🛠️ Getting Started
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
